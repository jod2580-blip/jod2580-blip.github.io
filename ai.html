01동향보고 초안 자동생성 완료
2026-11-09
과거 동향보고 3건을 예시(few-shot)로 넣어 200~400자 초안 생성. 사람은 확인·보완만.
  • 학습자료: 지산 유모차끼임 · 범물 쌍방폭행 · 수성못 E/S 넘어짐
  • 출력 항목: 제목 / 개요(일시·장소·유형·원인코드) / 주요내용 / 조치사항(시간순) / 기타
  • 효과: 20~30분 → 5분 목표 (확인·코드확정만 남음)
  • 사람 검토 항목: 미확인 칸, 부상정도, 원인코드 확정

02매뉴얼·법령 RAG 검색 완료
2026-11-11
법령 21건·편람·매뉴얼·동향보고를 800자/오버랩 100으로 청킹해 색인. 근거 조문까지 즉시 검색.
  • 청킹: 800자 목표 + 직전 카드 100자 겹침(문장 경계 보존)
  • 법령은 조문 중간을 자르지 않아 평균 1,523자
  • 색인: BM25 역색인 + 한글 2글자 조합(형태소 분석기 불필요)
  • 검색: 관련 카드 3~5장 0.05초 추출, 출처(문서·조문) 표시
